Data Platform for Excel

Put data from your organisation's approved Power BI models into Excel. Pick a workspace, a model, the fields you need and any filters, and get a table or a PivotTable that refreshes whenever you like, always as you. Nothing is hosted between Excel and Power BI.

Software bill of materials SHA-256 checksums Release notes
The installer is not yet code-signed, so Windows SmartScreen may say "Windows protected your PC". Choose More info, then Run anyway. To check the file, compare its SHA-256 with the checksums file.

What a PC needs

  • Windows 10 or 11 with Excel for Microsoft 365 (the desktop app). Excel for the web, Mac and mobile open the workbooks and show the values last saved in them.
  • The .NET 10 Desktop Runtime of the same bitness as Office. The installer checks for it and stops with a message if it is missing.
  • Local administrator rights. It is a per-machine install; every user of the PC gets the Data Platform tab.
  • Your organisation's configuration file, config.json: the tenant, the app registration and the approved workspaces. Without it the add-in has nothing to connect to. Your IT team prepares it with D8A; the deployment guide explains it.

Install

From the command line

From an administrator PowerShell, in the folder holding the MSI, with Excel closed. CONFIGDIR is the full path of a folder that holds config.json.

msiexec /i "DataPlatform-0.1.0-x64.msi" /qn /norestart CONFIGDIR="C:\Deploy\DataPlatform" /l*v "$env:TEMP\DataPlatform-install.log"

By double-click

Double-clicking the MSI also works. A double-click cannot pass CONFIGDIR, so afterwards copy config.json into %ProgramData%\D8A\DataPlatform\ as an administrator.

First use

  1. Every user gets the tab after their next Windows sign-in. To have it at once, run the registration once as yourself: 
    & "C:\Program Files\D8A\DataPlatform\D8A.DataPlatform.Register.exe" --register "C:\Program Files\D8A\DataPlatform\D8A.DataPlatform64.xll"
  2. Start Excel. The Data Platform tab is there (key tip: Alt, G). Choose Account › Sign in; the Windows account picker appears.
  3. Turn Excel's native-query approval off once: Data › Get Data › Query Options › Security, untick "Require user approval for new native database queries". Otherwise every load asks.
  4. New Table: workspace, model, perspective, fields, filters, Load.

A newer version installs over the old one with the same command and keeps config.json. Uninstall with msiexec /x "DataPlatform-0.1.0-x64.msi" /qn /norestart or from Settings › Apps. Intune and SCCM deployment, upgrades and troubleshooting are in the deployment guide.
